Key methods

What to remember

  • $ ("#id") selects an element by ID.
  • $ (".class") selects elements by class.
  • $ ("p") selects paragraph tags.
  • .text() inserts plain text.
  • .html() inserts HTML content.
  • .css() changes CSS styles.
