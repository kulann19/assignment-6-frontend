Animation notes

How it works

  • .animate() changes numeric CSS properties over time.
  • The duration controls how long an animation takes.
  • Chained animate() calls run in sequence.
  • .stop(true) clears a running animation before a new one starts.
$("#box").animate({
  width: "120px",
  left: "100px"
}, 600);
