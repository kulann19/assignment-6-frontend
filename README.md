# Assignment #6 — jQuery (Selectors, Effects, Animations)

**Student:** Kulan Alnur  
**Group:** SE-2524

A responsive, minimalist multi-page project demonstrating the jQuery topics from Assignment #6.

## Features

- **Task 0:** jQuery 3.7.1 CDN and `$(document).ready()`; prints `jQuery is ready!` in the browser console.
- **Task 1:** ID, class and tag selectors; `.text()`, `.html()` and `.css()`.
- **Task 2:** `.hide()`, `.show()` and `.toggle()`.
- **Task 3:** `.fadeIn()`, `.fadeOut()` and `.fadeToggle()`.
- **Task 4:** `.slideUp()`, `.slideDown()` and `.slideToggle()`.
- **Task 5:** `.append()`, `.prepend()` and `.remove()`.
- **Task 6:** `.attr()` updates an image `src` and a link `href`.
- **Task 7:** `.val()` and `.text()` create a live form preview.
- **Tasks 8–10:** basic, sequential and combined `.animate()` demonstrations.
- **Task 11:** image gallery with fading thumbnails and an enlarged lightbox preview.

## Run locally

1. Extract the ZIP archive.
2. Open `index.html` in a browser. For the most reliable local development experience, use the **Live Server** extension in Visual Studio Code.
3. Internet access is required to load jQuery from the CDN and the optional Google Fonts stylesheet.
4. Open the browser developer console with `F12` and check for `jQuery is ready!`.

## Publish with GitHub Pages

1. Create a GitHub repository and upload all project files while keeping the folder structure.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish the site and open the URL shown in the Pages settings.
